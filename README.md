# SmartLight AI

Projeto académico de Engenharia Informática.

## Objetivo

Desenvolver um sistema inteligente de iluminação
residencial utilizando ESP32, sensores e IA.

## Funcionalidades previstas

- Deteção de presença
- Medição da luminosidade ambiente
- Controlo automático de iluminação por PWM
- Estimativa de consumo energético
- Monitorização através de dashboard
- Previsão de consumo com Inteligência Artificial

## Arquitetura

ESP32 → MQTT → Backend → Base de Dados

O dashboard consulta o backend.
A IA utiliza dados históricos para gerar previsões.

## Tecnologias previstas

- ESP32 / C++ / PlatformIO
- MQTT / Mosquitto
- Python / FastAPI
- SQLite
- scikit-learn
- Dashboard Web
